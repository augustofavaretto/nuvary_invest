Principios da reescrita

  • 🎯Backend intacto — mesmo payload de cadastro (cpf/telefone sem mascara, data DD/MM/AAAA, aceiteTermos boolean), mesmas funcoes em authService.ts
  • 🌑Visual dark navy + ciano — bg #020817 + atmospherics radiais com rgba(6,182,212,*)
  • 🅰️Tipografia dual — Manrope (titulos, valores grandes) + Inter (paragrafos, labels)
  • 🖼️Logo PNG oficial — substitui SVG manual em todas as paginas publicas
  • ♻️Cleanup — components/auth/* (5 arquivos) e Header.tsx removidos; novos em components/public/{AuthLayout, LegalLayout, AuthFields}.tsx

📄 6 Paginas Reescritas

1. Landing page (/)

  • 1Hero com h1 gradient ciano + portfolio mock a direita
  • 2Beneficios — 6 cards (IA, Perfil, Educacao, Chatbot, Rebalanceamento, Monitoramento)
  • 3Como funciona — 3 steps com numeros gigantes em gradient ciano
  • 4Planos — Free vs Premium com badge "Mais escolhido"
  • 5Depoimentos — 4 testimonials com avatar gradient + estrelas
  • 6FAQ accordion — 5 perguntas frequentes
  • 7CTA gigante + footer com links Termos/Privacidade

2. Login (/login)

Email + senha, link "Esqueci minha senha", flag ?registered=true exibe mensagem pos-cadastro. Apos login, redireciona para /dashboard ou /questionario conforme verificarSeTemPerfil().

3. Cadastro (/cadastro)

Form com Nome + CPF + Data + Telefone + Email + Senha (com strength meter) + Confirmar + checkbox de aceite.

  • 🎭Mascaras visuais de CPF, Data e Telefone (apenas display)
  • 📨Backend recebe cpf.replace(/\D/g,'') e telefone.replace(/\D/g,'') sem mascara
  • 💪Senha calcula forca em tempo real (Fraca / Media / Forte)

4. Recuperar Senha (/recuperar-senha)

Input de email + Enviar instrucoes. Apos sucesso, mostra confirmacao com instrucoes para verificar a caixa de entrada.

5. Termos (/termos) e Privacidade (/privacidade)

LegalLayout com helpers LegalSection, LegalCallout, LegalBullets. 13 secoes cada documento, com eyebrow + h1 grande Manrope + ultima atualizacao + versao.

6. Redefinir Senha (/redefinir-senha)

Refeito no mesmo padrao. Apos sucesso, hard redirect via window.location.href = '/login'.

🅰️ Tipografia Manrope + Inter

📝 Hierarquia de fontes

Body (texto)Inter 400/500/600
MonoJetBrains Mono (apenas tickers)

Configuracao

// frontend/src/app/layout.tsx
import { Inter, JetBrains_Mono, Manrope } from "next/font/google";

const manrope = Manrope({
  variable: "--font-manrope",
  subsets: ["latin"],
  weight: ["500", "700", "800"],
});

<body className={`${inter.variable} ${manrope.variable} ${jetbrainsMono.variable}`}>

Uso via inline style: style={{ fontFamily: 'var(--font-manrope)' }}
