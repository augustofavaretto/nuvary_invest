👀 Reveal on Scroll

Cada card faz fade-in + slide-up (y: 24 → y: 0) quando entra na viewport. Aplicado em todas as secoes principais.

<motion.div
  initial={reducedMotion ? false : { opacity: 0, y: 24 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true, margin: '-60px' }}
  transition={{ duration: 0.5, delay: i * 0.07, ease: [0.16, 1, 0.3, 1] }}
>

Stagger por indice: cada card aparece 70-120ms depois do anterior, criando efeito de cascata. once: true evita reanimar no scroll-back.

📈 HeroPortfolioMock Animado

  • 1Linha do grafico desenha de pathLength 0 → 1 em 1.6s (Framer Motion suporta nativamente)
  • 2Barras de alocacao enchem de width 0% ate o valor com stagger (400ms inicial + 120ms entre barras)
  • 3Contador +12,4% usa useMotionValue + animate + useTransform para animar de 0 ate 12.4 sem re-renders
  • 4Glow de fundo ciano pulsa sutil (opacity + scale, 5s loop)
  • 5Fill area do grafico aparece 1.2s depois da linha (delay)

Trigger por viewport

Tudo controlado por useInView(ref, { once: true, margin: '-80px' }) — so anima quando o mock entra na tela.

Parallax dos glows do background

const { scrollY } = useScroll();
const glowTopY = useTransform(scrollY, [0, 800], ['0%', '20%']);
const glowBottomY = useTransform(scrollY, [0, 800], ['0%', '-15%']);

<motion.div style={{ y: glowTopY }} className="..." />

Os atmospherics ciano se movem lentamente em direcoes opostas conforme voce rola, criando profundidade.

💬 Secao Chat IA Preview

Nova secao #assistente entre "Como Funciona" e "Planos". Mostra um mock do Chat IA animado em loop, fiel ao visual de /chat real.

Layout (2 colunas em lg)

  • 📝Esquerda — titulo "Conversa, contexto e decisao" + 3 bullets de feature + CTA "Experimentar o assistente"
  • 💻Direita — <ChatPreviewMock /> animado

Sequencia de animacao (~12s por ciclo)

  • 1step='welcome' — bubble do bot com mensagem de boas-vindas aparece
  • 2step='prompts' — 3 pills aparecem com stagger (Devo rebalancear?, Proximas oportunidades, Analise da carteira)
  • 3step='user' — primeiro prompt vira destacado em ciano + bubble do usuario aparece a direita
  • 4step='thinking' — 3 dots ciano pulsam (typing indicator) por 1.4s
  • 5step='response' — bubble da IA aparece com efeito typewriter (22ms/caractere) + cursor "▋" piscando
  • 6step='complete' — pausa 5.5s e reinicia o ciclo
