📣 Banner Global de Upsell

Faixa horizontal renderizada no DashboardLayout, entre o TopBar e o <main>. Visivel em todas as paginas autenticadas para usuarios !isPremium.

Como funciona

  • 1DashboardLayout inclui <PremiumUpgradeBanner />
  • 2No mount: usePremium() retorna isPremium apos consultar Supabase
  • 3Le sessionStorage — se flag nuvary_premium_banner_dismissed = "1", oculta
  • 4Se isPremium ou rota em HIDDEN_ROUTES (/premium, /login, /cadastro, /questionario, /chat, /configuracoes), nao renderiza
  • 5Clica X → grava flag + esconde ate nova sessao do navegador
  • 6Clica "Fazer upgrade" → router.push('/premium')

👑 Whitelist Premium (acesso vitalicio)

Lista de emails que recebem acesso Premium sem precisar passar pelo Mercado Pago. Util para conta do dono, testes internos e contas de demo.

📁 frontend/src/services/premiumService.ts
export const PREMIUM_WHITELIST: readonly string[] = [
  'investnet123@gmail.com',
  'luciano.cruz@atitus.edu.br',
  'vitorbgirardi13@gmail.com',
];

export function isWhitelistedPremium(email: string | null | undefined): boolean {
  if (!email) return false;
  return PREMIUM_WHITELIST.includes(email.toLowerCase());
}

Como funciona

  • 1getSubscriptionState() verifica o email do usuario logado
  • 2Se estiver na PREMIUM_WHITELIST, retorna status: 'active', plan: 'anual', expiresAt: null (vitalicio) — sem consultar Supabase
  • 3isPremiumActive() ja trata expiresAt: null como vitalicio, entao usePremium() e todos os gates funcionam automaticamente
  • 4Comparacao case-insensitive — Investnet123@Gmail.com funciona igual

Para adicionar mais emails

Editar o array PREMIUM_WHITELIST em premiumService.ts e fazer deploy. Sem migration, sem chamada API.
