🪙 Cripto → CoinGecko

O Alpha Vantage tornou o endpoint CURRENCY_EXCHANGE_RATE premium e passou a devolver o campo Information (que o codigo nao tratava). Resultado: o preco de cripto nunca atualizava, deixando valores-lixo gravados (BTC R$ 29,72) e sem alertas reais.

Novo servicebackend/src/services/coingecko.js (cache 60s, mapeia 10 tickers, change 24h)
ControllercryptoController.getExchangeRate usa CoinGecko, default BRL
FrontendfetchCryptoPrice pede BRL e usa o preco direto (sem x5)

Validado ao vivo: BTC = R$ 319.978 (bate com o mercado).

Auto-cura dos alertas

No primeiro refresh com o preco correto, a variacao gigante vs o valor-lixo passa do limite de 50% e o sistema reseta o baseline sem alertar. Dai em diante, variacoes reais ≥ 5% disparam normalmente.

💵 Dolar → BCB PTAX

Acoes US (fallback Finnhub) convertiam USD→BRL com USD_TO_BRL = 5.0 fixo, subvalorizando ~3%. Novo endpoint GET /api/bcb/dolar (serie SGS 1, PTAX diaria) fornece o cambio real; o fetchUsdToBrl() usa com cache de 1h e cai no 5,0 so como fallback.

🏢 FIIs → token Brapi

Acoes B3 funcionam no Brapi sem token, mas FIIs exigem token valido. Dois bugs corrigidos:

  • 🔑config lia so BRAPI_API_TOKEN, mas o README pedia BRAPI_TOKEN — agora aceita os dois
  • 🚫o controller mandava token=undefined (Brapi respondia INVALID_TOKEN) — agora so anexa o token se existir

Confirmado no deploy: HGLG11 = R$ 154,95 (token OK).
