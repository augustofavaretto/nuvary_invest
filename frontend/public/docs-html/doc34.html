⌨️ Chat IA — Textarea com auto-resize (commit 4b7b0c5)

O input do chat era um <Input> shadcn de uma linha. Texto longo (ex: prompt do pill "Insights da carteira") ficava cortado horizontalmente com scroll, sem indicacao visual de quanto faltava.

Mudancas em Chatbot.tsx

  • Trocado <Input> por <textarea> com rows=1 inicial, min-h: 48px, max-h: 200px, resize-none
  • useEffect ajusta height para scrollHeight a cada mudanca em inputValue — cresce ate o limite, depois ganha scroll vertical interno
  • Enter envia, Shift+Enter quebra linha (padrao Claude/ChatGPT)
  • e.nativeEvent.isComposing check — IME (japones/chines etc.) usa Enter para confirmar caracteres; nesse caso nao envia
  • inputRef tipado como HTMLTextAreaElement (era HTMLInputElement); import do shadcn Input removido

🤖 Sugestões IA com contexto da carteira (commit 1eb0c0a)

Antes, getAISuggestions(perfilRisco) so enviava ao backend o tipo de perfil — sugestoes ficavam genericas, sem considerar ativos reais nem movimentacoes.

Nova assinatura

getAISuggestions(
  perfilRisco: string,
  contexto?: {
    totalValue?: number;
    totalInvested?: number;
    profitPercentage?: number;
    byClass?: Array<{ name: string; percentage: number }>;
    numAtivos?: number;
    ultimasMovimentacoes?: Array<{
      tipo: 'compra' | 'venda';
      ticker: string;
      quantity: number;
      price: number;
      created_at: string;
    }>;
  }
): Promise<string>

Prompt resultante

Voce e o assistente Nuvary Invest, consultor financeiro brasileiro.
Analise o perfil e a carteira do usuario e gere uma sugestao curta
(maximo 300 caracteres, 2-3 frases). Seja direto, especifico e use
cifras quando relevante. Nao use markdown nem listas. Portugues
brasileiro.

PERFIL: arrojado

DADOS DA CARTEIRA:
- Patrimonio atual: R$ 19.198,52
- Total investido: R$ 19.564,74 (-1,87%)
- 12 ativos
- Alocacao: Renda Variavel 30.7%, Renda Fixa 20.8%, FIIs 11.0%, Internacional 8.0%, Caixa 29.5%
- Ultimas movimentacoes: 10/05 COMPRA PETR4 (100@R$ 48.66); 08/05 VENDA HGLG11 (50@R$ 168.00); ...

useDashboardData.ts

  • Helper buildContexto(portfolio, transacoes) converte PortfolioData + Transaction[] para o formato esperado
  • portfolioRef e transacoesRef guardam dado fresco entre refreshes
  • Fetch inicial busca getPortfolioData() + getTransactions() em paralelo com market/news
  • refreshAI() tambem recarrega esses dados antes de chamar a IA — garante que insights refletem a carteira atual
  • Limite de 5 movimentacoes mais recentes (nao infla o prompt)
Mensagem de fallback ainda aparece se o backend retornar erro (HTTP nao-200 em /api/ai/suggestion). Causas comuns: OPENAI_API_KEY nao configurada no projeto Vercel do backend, rate limit, ou endpoint fora do ar. Conferir em nuvary-invest-backend.vercel.app.
