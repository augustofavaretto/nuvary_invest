🛑 Cancelamento de Assinatura

O usuario com assinatura paga agora gerencia o plano em /configuracoes, numa secao que so aparece para quem tem assinatura real (whitelist vitalicio nao ve, pois nao ha o que cancelar).

Fluxo no backend

  • 1Front chama POST /api/mercadopago/cancel-subscription com o userId
  • 2O controller valida que existe assinatura active e busca o mp_preapproval_id no profile
  • 3Se houver preapproval (assinatura de cartao), cancela a recorrencia no Mercado Pago via cancelPreapproval()
  • 4Marca o profile como cancelled — o acesso continua valido ate subscription_expires_at

Regra de acesso pos-cancelamento

O isPremiumActive() passou a honrar o status cancelled enquanto a data de expiracao for futura: o usuario ja pagou o periodo vigente, entao mantem o Premium ate o fim — so nao ha renovacao.

export function isPremiumActive(state) {
  if (state.status !== 'active' && state.status !== 'cancelled') return false;
  if (!state.expiresAt) return state.status === 'active'; // vitalicio (whitelist)
  return new Date(state.expiresAt).getTime() > Date.now();
}

Na UI, a secao mostra o plano (Mensal/Anual), o status (Ativa/Cancelada) e a data de renovacao/expiracao. Quando ja cancelada, oferece "Reativar Premium".

⚡ Performance dos Graficos

Antes, carteira e relatorios faziam um waterfall que bloqueava o render: esperavam refreshAllPrices() terminar (chamadas externas em serie) antes de mostrar qualquer grafico.

O que mudou

  • 1Render imediato — as paginas carregam primeiro os valores ja salvos no Supabase (getPortfolioData()) e pintam os graficos na hora
  • 2Precos em background — refreshAllPrices() roda depois; so re-renderiza se algum preco mudou
  • 3Busca paralela — o loop de precos virou Promise.all; o tempo cai de "soma das latencias" para "a maior latencia"
  • 4CDI nao bloqueia — em relatorios, a busca do CDI virou fire-and-forget

Resultado: no refresh/login, os graficos aparecem assim que o banco responde (1 round-trip), e os precos de mercado entram suavemente depois, sem tela em branco.
