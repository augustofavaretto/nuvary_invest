Visão Geral

💡

O Chat IA não foi "treinado". Ele usa prompt engineering — técnica que injeta contexto estruturado em cada chamada à API do GPT-4o, fazendo o modelo se comportar como um especialista em investimentos brasileiro sem necessidade de fine-tuning.

O que é Prompt Engineering?

É a arte de instruir um LLM (Large Language Model) via texto de forma precisa. Em vez de treinar um modelo do zero (custo de milhões de dólares e meses de trabalho), você monta um prompt rico que guia o comportamento do GPT em tempo de execução.

No caso da Nuvary, o prompt é montado dinamicamente a cada mensagem, combinando:

  • Instruções fixas de identidade e comportamento
  • Dados de mercado em tempo real (BCB)
  • Perfil de risco do usuário logado
  • Carteira real do usuário
  • Histórico da conversa atual
🔑

Modelo atual: GPT-4o (OpenAI) — o modelo mais capaz disponível, com janela de contexto de 128k tokens e conhecimento atualizado até abril de 2024. Dados posteriores (Selic atual, IPCA recente) são fornecidos via BCB em tempo real.

Camada 1 — System Prompt

O que contém

Bloco Conteúdo
Identidade "Você é o Nuvary, assistente virtual de investimentos da Nuvary Invest"
Restrição de Escopo Bloco RESTRIÇÃO DE ESCOPO: define tópicos permitidos (investimentos, educação financeira, plataforma) e proibidos (receitas, esportes, política, saúde, programação genérica, piadas, role-play). Inclui regras anti-bypass contra prompt injection e "modo livre". Mensagem de recusa padronizada para tópicos fora do escopo.
Data Data de hoje em pt-BR — permite o GPT calcular vencimentos, prazos e sazonalidade
Plataforma O que a Nuvary Invest oferece (Dashboard, Carteira, Relatórios, Trilhas, Perfil)
Mercado BR IBOVESPA, IFIX, B3, tipos de ativo, reguladores (CVM, ANBIMA, BCB)
Tributação IR ações 15–20%, FIIs isentos PF, renda fixa tabela regressiva, cripto 15–22,5%
Regras Sempre PT-BR, markdown, nunca garantir retornos, citar fontes confiáveis
⚠️

O system prompt nunca aparece para o usuário — é enviado como role system na API e serve como contrato invisível com o modelo.

Camada 2 — Dados de Mercado em Tempo Real

Por que isso é fundamental?

O GPT-4o tem conhecimento até abril de 2024. A Selic, CDI e IPCA mudam com frequência. Sem dados reais, o assistente responderia com taxas desatualizadas — o que seria problemático para comparações de rentabilidade e sugestões de alocação.

Fonte: Banco Central do Brasil — SGS (Sistema Gerenciador de Séries)

Indicador Série SGS Descrição Relevância no chat
Selic s432 Meta COPOM (% a.a.) Benchmark de renda fixa, comparação de CDBs, Tesouro Selic
CDI s4389 Anualizado base 252 Cálculo de "X% do CDI", rentabilidade de LCIs/LCAs/CDBs
IPCA s13522 Acumulado 12 meses (%) Análise de Tesouro IPCA+, inflação real dos investimentos
IGP-M s189 Mensal (%) Referência para debêntures e contratos corrigidos por IGP-M

Como é inserido no prompt

## Indicadores de mercado em tempo real (Banco Central do Brasil)
- Selic (meta COPOM): 13.75% a.a. (ref. 19/03/2026)
- CDI anualizado (base 252): 13.65% a.a. (ref. 19/03/2026)
- IPCA acumulado 12 meses: 5.06% (ref. fev/2026)
- IGP-M mensal: 0.32% (ref. mar/2026)
Use estes dados reais nas suas respostas sobre rentabilidade, comparação de ativos e projeções.
✅

Fallback silencioso: se a API do BCB estiver fora do ar, o bloco de dados de mercado é simplesmente omitido do prompt. O chat continua funcionando com o conhecimento de treino do GPT-4o, sem quebrar a experiência do usuário.

Camada 5 — Histórico da Conversa

O GPT-4o não possui memória persistente entre chamadas de API. Para manter a conversa coerente, o frontend reenvia todas as mensagens anteriores da sessão em cada nova requisição.

// Estrutura enviada ao backend
[
  { "role": "system",    "content": "[system prompt completo]" },
  { "role": "user",      "content": "o que é CDI?" },
  { "role": "assistant", "content": "CDI é a taxa..." },
  { "role": "user",      "content": "e como comparo com Selic?" }
]
⚠️

Limite de tokens: conversas muito longas podem exceder o contexto do modelo. O histórico é mantido integralmente por sessão — sem truncamento por enquanto. Conversa nova = contexto zerado.

Parâmetros da API OpenAI

gpt-4o Modelo Mais capaz da OpenAI. 128k tokens de contexto. Conhecimento até abr/2024.
0.5 Temperature Equilibrado entre precisão e naturalidade. 0 = robótico, 1 = muito criativo.
1200 Max Tokens Limite de tokens na resposta (~900 palavras). Evita respostas excessivamente longas.

Por que temperature 0.5?

Temperature Comportamento Adequado para
0.0 – 0.2 Determinístico, sempre a mesma resposta Extração de dados, classificação
0.3 – 0.6 Preciso mas com variação natural Chat financeiro (nosso caso)
0.7 – 1.0 Criativo, mais surpresas Escrita criativa, brainstorm

Estrutura do Código

assistantChat() — openai.js

async assistantChat(message, conversationHistory = [], userContext = {}) {
  // 1. Extrai perfil e carteira do contexto
  const { profile, portfolio } = userContext;

  // 2. Busca dados do BCB (com fallback silencioso)
  let market = null;
  try { market = await this.fetchMarketData(); } catch {}

  // 3. Monta system prompt com todas as camadas
  let systemPrompt = `Você é o Nuvary...`;
  if (market)    systemPrompt += `\n## Indicadores BCB\n...`;
  if (profile)   systemPrompt += `\n## Perfil do usuário\n...`;
  if (portfolio) systemPrompt += `\n## Carteira atual\n...`;

  // 4. Monta array de mensagens
  const messages = [
    { role: 'system', content: systemPrompt },
    ...conversationHistory,
    { role: 'user', content: message },
  ];

  // 5. Chama GPT-4o com parâmetros calibrados
  return await this.client.chat.completions.create({
    model: 'gpt-4o',
    messages,
    max_tokens: 1200,
    temperature: 0.5,
  });
}

fetchMarketData() — busca BCB em tempo real

async fetchMarketData() {
  // Séries SGS do Banco Central
  const SGS = {
    selic_meta:   432,   // Meta COPOM
    cdi_anual:    4389,  // CDI base 252
    ipca_12m:     13522, // IPCA acumulado 12m
    igpm_mensal:  189,   // IGP-M mensal
  };

  // Busca as 4 séries em paralelo
  const [selic, cdi, ipca, igpm] = await Promise.allSettled([
    fetchSGS(SGS.selic_meta),
    fetchSGS(SGS.cdi_anual),
    fetchSGS(SGS.ipca_12m),
    fetchSGS(SGS.igpm_mensal),
  ]);
  // Promise.allSettled: falha parcial não quebra o restante
}
