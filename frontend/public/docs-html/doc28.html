📈 Calculos de Rentabilidade e Lucro/Prejuizo

1. Patrimonio Total (totalValue)

totalValue = SUM(asset.totalValue) para todos os ativos
Soma simples de todos os valores atuais. Nao envolve multiplicacao.
Exemplo

CDB Inter R$5.000 + HGLG11 R$15.603 + BTC R$39.089 = R$59.692

2. Total Investido (totalInvested)

O custo de aquisicao difere por tipo de ativo:

// Renda Fixa e Tesouro
investido = asset.quantity // o proprio R$ aplicado
quantity JA e o valor em reais — nao multiplicar pela taxa.
// Renda Variavel, FIIs, Internacional, Cripto
investido = asset.quantity x asset.averagePrice
cotas x preco medio de compra.
// portfolioService.ts — calculatePortfolioData()
const totalInvested = assets.reduce((sum, a) =>
  sum + (a.type === 'renda_fixa' ? a.quantity : a.quantity * a.averagePrice), 0);
Exemplo com carteira mista
AtivoTipoQtyPreco MedioInvestido
CDB-INTERrenda_fixaR$5.00017.88% a.a.R$5.000 (= qty)
HGLG11fiis100 cotasR$156,03R$15.603 (= 100 x 156,03)
BTCrenda_variavel0.1R$355.568R$35.556 (= 0.1 x 355.568)
Total InvestidoR$56.159

3. Lucro / Prejuizo (totalProfit)

totalProfit = totalValue - totalInvested
Positivo = lucro | Negativo = prejuizo

4. Rentabilidade % (profitPercentage)

profitPercentage = (totalProfit / totalInvested) x 100
Se totalInvested = 0, retorna 0 para evitar divisao por zero.

5. Variacao % por Ativo (variation)

// Renda Fixa: sempre 0% (sem cotacao de mercado)
variation = 0

// Renda Variavel, FIIs, Internacional, Cripto:
variation = ((currentPrice - averagePrice) / averagePrice) x 100
Exemplo — HGLG11

Preco medio: R$156,03 | Preco atual: R$170,00

Variacao = ((170 - 156,03) / 156,03) x 100 = +8,95%

6. Percentual da Carteira e do Produto

percentageOfPortfolio = (asset.totalValue / totalValue) x 100
percentageOfProduct = (asset.totalValue / productTotal) x 100
productTotal = soma dos ativos da mesma categoria (Renda Fixa, FIIs, etc.)

+ Adicionar Ativo

Fluxo do modal AddAssetModal.tsx com 3 steps:

1
Selecionar Categoria Renda Fixa, Tesouro Direto, Renda Variavel, FIIs, Internacional, Criptomoedas
2
Selecionar Ativo Lista pre-definida de 100+ ativos com busca. Opcao de ativo personalizado.
3
Preencher Detalhes e Confirmar Quantidade, preco medio (ou taxa % a.a. para renda fixa), corretora. Sistema busca preco atual automaticamente ao confirmar.

Busca automatica de preco ao adicionar

// portfolioService.ts — fetchAssetPrice()
// Renda Fixa: busca CDI do BCB se nome contiver "X% CDI"
// Tesouro: busca taxa de compra via /api/tesouro/rates
// B3 / FIIs: busca via Brapi /api/brapi/quote/:ticker
// BDRs: busca preco US via Finnhub e converte para BRL
// Cripto: busca via Alpha Vantage (USD) x USD_TO_BRL (5.0)
// Internacional ETFs: busca SPY como proxy para IVVB11/SPXI11

Calculo CDI automatico

// Se o nome do ativo contiver "120% CDI":
// regex: /(\d+(?:[.,]\d+)?)\s*%\s*(?:do\s+)?CDI/i
// Busca CDI atual do BCB (ex: 14.90% a.a.)
// Taxa efetiva = CDI x percentual / 100
// Ex: "CDB Inter 120% CDI" → 14.90 x 1.20 = 17.88% a.a.

Persistencia no Supabase

// addAsset() → INSERT em portfolio_assets
{
  id, user_id, name, ticker, type,
  quantity, average_price, current_price,
  total_value, variation, broker, created_at
}

↓ Vender Ativo

Operacao disponivel no card Sua Carteira por Produto. O botao Vender abre o SellAssetModal.tsx.

Tipos de Venda

TipoAcao no BancoResultado
Venda Total
Clique em "Venda Total" ou qtd = max		 removeAsset(assetId)
DELETE em portfolio_assets		 Ativo removido da carteira
Venda Parcial
Informar quantidade menor que o total		 updateAsset(assetId, ...)
UPDATE em portfolio_assets		 Ativo permanece com quantidade reduzida

Calculo da Venda Parcial

// Renda Fixa (baseado em valor R$)
novaQuantidade = asset.quantity - valorResgatado
novoTotalValue = novaQuantidade

// Renda Variavel / FIIs / Internacional (baseado em cotas)
novaQuantidade = asset.quantity - cotasVendidas
novoTotalValue = novaQuantidade x asset.currentPrice
Exemplo — Venda parcial FII HGLG11

Posicao: 100 cotas | Preco atual: R$170,00 | Vende: 30 cotas

Nova quantidade: 70 cotas | Novo total: 70 x R$170 = R$11.900

Exemplo — Resgate parcial CDB

Posicao: R$5.000 | Resgata: R$2.000

Nova quantidade: R$3.000 | Novo total: R$3.000

Registro em Extratos

Toda venda e automaticamente salva na tabela portfolio_transactions do Supabase:

// saveTransaction() — chamado antes de removeAsset() ou updateAsset()
{
  user_id, tipo: 'venda', ticker, name, asset_type,
  quantity: qtdVendida,
  price: precoAtual,           // currentPrice para variavel; qtdVendida para renda_fixa
  total_value: valorDaVenda,
  created_at: now()
}

As vendas aparecem na aba Extratos de Relatorios com badge vermelha "Venda" e podem ser filtradas pelo dropdown Tipo.

🗑 Remover Ativo

O botao lixeira remove o ativo diretamente sem registrar em extratos (diferente da venda). Use para corriger erros de cadastro.

// removeAsset(assetId)
DELETE FROM portfolio_assets WHERE id = assetId AND user_id = currentUser
Diferenca: "Remover" e para correcoes de cadastro — nao aparece nos extratos. "Vender" registra a operacao em portfolio_transactions e aparece nos relatorios.

🔄 Refresh de Precos (Cache 15 min)

Implementado em refreshAllPrices() no portfolioService.ts. Atualiza precos de mercado dos ativos de renda variavel, FIIs e internacional.

Quando e chamado

SituacaoComportamento
Abre /carteiraChama refreshAllPrices(false) — respeita cache 15 min
Clica "Atualizar"Chama refreshAllPrices(true) — ignora cache, busca forcado
Cache valido (<15 min)Retorna false imediatamente — nenhuma chamada a APIs externas

O que e atualizado

Renda Variavel, FIIs, Internacional — preco atualizado via Brapi (B3) ou Finnhub (EUA)
Renda Fixa e Tesouro — nao atualiza. A taxa e contratada e fixa; nao existe cotacao de mercado.

Fluxo do refresh

refreshAllPrices(force = false):
  1. Verifica localStorage['nuvary_price_cache_ts']
  2. Se cache valido e !force → retorna false (sem chamada de API)
  3. Busca todos os ativos do Supabase (getAllAssetsFromDB)
  4. Filtra: apenas ['renda_variavel', 'fiis', 'internacional']
  5. Para cada ativo:
     a. fetchAssetPrice(ticker, type) → preco atual
     b. variation = ((currentPrice - averagePrice) / averagePrice) x 100
     c. totalValue = quantity x currentPrice
     d. UPDATE portfolio_assets SET current_price, total_value, variation
  6. Atualiza localStorage timestamp
  7. Frontend relê os dados atualizados do Supabase

📋 Extratos — Historico de Transacoes

A aba Extratos em Relatorios consolida dois tipos de dados:

TipoFonteBadgeQuando aparece
Compra Tabela portfolio_assets (cada ativo = uma compra) Compra Sempre que o ativo existir na carteira
Venda Tabela portfolio_transactions (tipo = 'venda') Venda Apos cada operacao de venda (total ou parcial)

Filtros Disponíveis

  • Busca por ticker/nome — campo de texto livre
  • Tipo — Todos | Compra | Venda
  • Categoria — Todas | Renda Fixa | Acoes B3 | FIIs | Internac.

  • Carteira por Corretora — seta redireciona para Extratos ja filtrado pela corretora clicada

URL gerada: /relatorios?aba=extratos&categoria=FIIs ou /relatorios?aba=extratos&corretora=XP+Investimentos

🔄 Fluxo Completo de Dados

ADICIONAR ATIVO
  Usuario preenche modal
    → fetchAssetPrice() — busca preco/taxa atual
    → addAsset() → INSERT portfolio_assets (Supabase)
    → loadData() → getPortfolioData() → calcula KPIs
    → UI atualizada

ATUALIZAR PRECOS (botao "Atualizar")
  handleRefresh()
    → refreshAllPrices(force=true)
       → para cada ativo de renda variavel/FIIs/internacional:
         → fetchAssetPrice() → UPDATE portfolio_assets
    → getPortfolioData() → recalcula tudo
    → UI atualizada

VENDER ATIVO (parcial)
  Usuario informa quantidade no SellAssetModal
    → saveTransaction('venda') → INSERT portfolio_transactions
    → updateAsset() → UPDATE portfolio_assets (nova qty, totalValue)
    → loadData() → getPortfolioData() → recalcula KPIs
    → UI atualizada

VENDER ATIVO (total)
  Usuario clica "Venda Total"
    → saveTransaction('venda') → INSERT portfolio_transactions
    → removeAsset() → DELETE portfolio_assets
    → loadData() → getPortfolioData() → recalcula KPIs
    → UI atualizada

REMOVER ATIVO (lixeira)
  Confirmacao do usuario
    → removeAsset() → DELETE portfolio_assets
    → handleRefresh() → UI atualizada
    (SEM registro em portfolio_transactions)
