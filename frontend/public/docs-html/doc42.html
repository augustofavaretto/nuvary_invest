✉️ Pagina /confirme-email

Antes, apos o cadastro, o usuario caia em /login?verifique-email=1 (so um aviso). Agora vai para a pagina dedicada /confirme-email?email=..., no mesmo visual das telas de auth (AuthLayout).

  • 📧Mostra o e-mail do usuario e a instrucao de clicar no link de ativacao
  • 🔗Botao "Abrir meu e-mail" que leva direto a caixa de entrada
  • 🗑️Aviso para checar o spam + link "Voltar ao login"

O link de confirmacao do Supabase continua apontando para /questionario, entao apos confirmar o usuario cai no questionario e depois na carteira (onde o tour inicia).
