🗑️ Remocao do Tesouro Direto

O Tesouro Direto era uma das categorias de ativo da carteira, com busca automatica de taxas via backend. Como a API estava com problema e a opcao ja nao era oferecida, a feature foi removida por inteiro.

Frontend

  • 🏷️Tipo 'tesouro' retirado de CategoryId
  • 🗺️TESOURO_TICKER_TO_NOME, fetchTesouroDiretoRate() e o branch em fetchAssetPrice() removidos
  • 💼Card da categoria "Tesouro Direto" retirado de /carteira (+ import Landmark orfao)
  • 📊'tesouro' removido do isFixed (carteira) e do FIXED_INCOME_TYPES (SellAssetModal)

Backend

  • 🔌routes/tesouroDireto.js + controllers/tesouroDiretoController.js deletados
  • 🚫Mount /api/tesouro removido do app.js

✅ O que foi mantido (de proposito)

Tesouro Direto continua sendo um investimento real, entao o conteudo educativo sobre ele permanece — so a feature de carteira saiu.

Trilhas EducativasVideos "Tesouro Direto: Guia Completo" e "Prefixado ou IPCA+?" (categoria Renda Fixa)
Chat IAO assistente continua sabendo explicar Tesouro Direto
QuestionarioOpcoes de perfil de risco citando Tesouro Selic/IPCA+
ANBIMA/api/anbima/titulos-publicos (separado, nao usado pelo front)

🗂️ Documentacao por Categoria

A pagina /docs deixou de ser uma lista cronologica plana e ganhou uma barra de abas que filtra os documentos por area do produto.

  • 📑Abas: Todos, Landing, Dashboard, Carteira, Chat IA, Relatorios, Trilhas, Configuracoes e Backend
  • 🔌A aba Backend traz uma referencia das rotas /api/* e das tabelas do Supabase
  • 🪞O "HTML Original" (index.html) recebeu o mesmo menu de pills com filtro

🗄️ Dados existentes

Se algum usuario tiver cadastrado Tesouro antes da remocao, podem existir linhas em portfolio_assets com type='tesouro'. Para reaproveita-las como renda fixa: 
UPDATE portfolio_assets SET type='renda_fixa' WHERE type='tesouro';

Validado com tsc, build e node --check no backend — sem quebra de runtime.
