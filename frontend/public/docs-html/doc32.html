🎯 Contexto do redesign

O briefing rebrand frontend nuvary invest.md propôs um redesign UI/UX completo do app, na direção "Glass + Bento Grid dark-first" (estilo Linear / Vercel / Apple), com Liquid Glass na navigation layer e Bento Grid nos dashboards. As 4 primeiras tarefas — todas aditivas, sem quebrar telas existentes — formam a foundation desse novo visual.

Adaptacao a Tailwind v4: o briefing assumia Tailwind v3 com tailwind.config.ts. O projeto ja usa Tailwind v4 (config inline via @theme em globals.css). Tokens e utilities da paleta brand foram declarados como variaveis CSS + @theme inline em vez de criar um arquivo de config tradicional.

🎨 Tarefa 1 — Design Tokens + Fonts (commit c79427b)

src/styles/tokens.css (novo)

Paleta navy/cyan (escala 50-800/700), gradientes (--gradient-brand, --gradient-cta, --gradient-hero, --gradient-glow), sombras (--shadow-tile, --shadow-cta), superficies light/dark (--bg-base, --bg-elevated, --bg-card, --bg-glass-nav, --bg-glass-hover), bordas (--border-subtle, --border-default, --border-strong) e tokens de texto.

A11y queries inclusas

@media (prefers-reduced-transparency: reduce) {
  :root {
    --bg-glass-nav:   var(--bg-elevated);
    --bg-glass-hover: var(--bg-card);
  }
}

@media (prefers-contrast: more) {
  :root { --border-strong: var(--cyan-700); }
  .dark { --border-strong: var(--cyan-400); }
}

globals.css

Importa tokens.css e estende @theme inline com:

  • Cores brand como utilities Tailwind: bg-navy-500, text-cyan-400, border-cyan-500, etc.
  • Sombras: shadow-tile, shadow-tile-hover, shadow-cta, shadow-cta-hover
  • Animacoes: animate-aurora, animate-aurora-slow, animate-pulse-glow, animate-shimmer
  • Backgrounds em gradiente: bg-gradient-brand, bg-gradient-cta, bg-gradient-hero, bg-gradient-glow

Fonts

src/app/layout.tsx:

  • Inter — pesos 400, 500, 600, 700, 800 (era so ate 700); display: swap
  • JetBrains Mono substitui Geist Mono — para valores monetarios, %, datas, tickers

src/lib/format.ts (novo)

Helpers pt-BR centralizados: formatBRL, formatBRLCompact, formatPercent, formatDelta (com sinal explicito), formatDateBR. Use em qualquer lugar que exiba numero para garantir BRL + virgula decimal + tabular-nums.

ThemeContext preservado: o briefing pedia migrar para next-themes com enableSystem={false}. O projeto manteve ThemeContext proprio porque a feature de deteccao automatica do tema do SO da v4.5.0 nao se traduz 1:1 (next-themes precisaria de configuracao diferente). Pode ser revisitado em sessao futura.

🪟 Tarefa 2 — Glass Primitives (commit 548c213)

4 componentes em src/components/glass/. Todos respeitam a regra Apple: glass apenas em navigation layer (sidebar, topbar, modais, chat panel, CTAs). Tiles de dados (Bento) usam bg-bg-card opaco.

ComponenteResponsabilidadeProps principais
GlassNav Container glass para sidebar/topbar/bottombar as, side (top/bottom/left/right controla qual borda recebe divider)
GlassCard Card glass para overlays, tooltips, modais variant (regular/clear/elevated), interactive, enableRefraction (SVG feTurbulence Chromium-only)
GlassButton CTAs com spring physics + shimmer no hover variant (regular/prominent/ghost), size (sm/md/lg); prominent = CTA brand com gradient + shadow-cta
LiquidGlassEffect Destaque premium (icone chat IA, badge Premium, CTA hero) intensity 1-3 controla blur + glow; implementacao CSS pura (sem dep liquid-glass-react)

Fallbacks de a11y/compatibilidade

  • Quando backdrop-filter nao suportado (Firefox antigo): cai para bg-bg-elevated opaco via supports-[not_(backdrop-filter:blur(0))]:
  • Focus ring ciano (focus-visible:ring-2 focus-visible:ring-cyan-400) em todos os botoes
  • Spring physics via framer-motion ja existente (briefing pedia motion; mantemos framer-motion@12 para nao quebrar ~30 componentes que ja importavam)

⚠️ Regras de ouro do redesign

  1. Nenhuma cor fora do brandbook. Tudo deriva de #0B1F33, #00B8D9 ou tokens semanticos.
  2. Glass so em navigation layer. Tiles de dados sao bg-bg-card opaco.
  3. Inter + JetBrains Mono. Sem Geist, sem SF Pro, sem Cal Sans.
  4. Dark mode default no app. Light em landing/auth.
  5. Bento Grid e arquitetura de informacao. Tile maior = mais importante.
  6. Mobile-first com fallbacks. Detectar suporte a backdrop-filter e degradar graciosamente.
  7. Compliance: cards de sugestao precisam do disclaimer no rodape.
  8. Nunca animar backdrop-filter. Anime so opacity e transform.
  9. WCAG AA minimo. Texto sobre glass = contraste verificado.
  10. Performance > efeitos. Se o device nao aguenta glass, mostre solid background.
